  one source tree (configure artifacts trip meson's conflict check); the
  upstream `parallel_schedule` runs unchanged under `meson test --suite
  regress`. Autoconf kept as legacy escape hatch only. (RULES §9 amendment.)

  observed live (cargo `E0425 cannot find function version_cstr`; SQL test
  failed with `ERROR: extension "iceberg" is not available` against the
  extension-less temp install) before any implementation existed.
- **Format-generic naming** (user decision 2026-11-19): `pgdatalake-core` +
  `lakehouse` SQL surface, `-Ddatalake` meson feature, `lakehouse-dev`
  branch, `lakehouse-*` make targets. Done *before* M1 to avoid a sweeping
  rename; all specs amended with §7 Superseded notes, not silently.
- **[core-allowlist] patch hygiene**: 3 patches so far, each with rationale +
  Spec reference in the commit message (meson_options.txt,
  src/backend/access/meson.build, root Makefile forward). Target: never grows
  without §3 review. No C-source core patches yet (none needed for M0).

## What the TDD loop / ceremony caught late

- `lakehouse-check` resolved the cargo manifest path as
  `src/test/backend/...` — the milestone-gate target never worked as written.
  Caught by the cold-room smoke ceremony (step 4), not by TDD, because make
  targets are test-less scaffolding (the allowed M0 exception). Lesson: give
  even "scaffolding" targets a trivial smoke assert (the gate now effectively
  has one, via the ceremony).
- meson custom_target ordering: the extension compiled before the cbindgen
  header existed (racy). Fixed by declaring the header as a dependency
  source. Lesson: in meson, generated headers must be in `sources:`/deps of
  the consumer, not just referenced by include path.

## Process changes for M1

1. Wire `scripts/gen_fixtures.py` early (M1 week 1) so REST-conformance tests
   are not blocked on hand-made fixtures.
2. Run `gh run list` right after every push — the first datalake-ci run
   failed silently for ~75 minutes (stale fixture image names) before anyone
   looked.
3. Keep the smoke ceremony cold-room script under version control
   (`scripts/` or retro/) so gate runs are reproducible with one command.
4. Flip GitHub default branch `master` → `main` (harness denied `gh repo
   edit`; needs a manual action), then delete `origin/master`.
